# data/

`companies_seed.zip` — стартовая база компаний date.gov.md (внутри
`companies.db`, около 200 записей публичного реестра, накопленных утилитой).

Её скачивает мастер настройки после установки (`setup_wizard.py`, в MSI —
«ContragentiSetup.exe») по ссылке из `release.json` (`database.zip`) и
сливает с локальной `companies.db`: новые ключи (IDNO) добавляются,
существующие записи пользователя не трогаются. Та же копия кладётся в MSI
как запасной вариант для компьютера без интернета.

Пересобрать из своей базы: `python tools/make_seed.py`.
