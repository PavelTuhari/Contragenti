## Habr

**Заголовок** (первая строка файла, в редакторе он идёт в отдельное поле — из тела
его нужно убрать, иначе продублируется):

> Delphi, Oracle и C++ оказались удобным стеком для ИИ-агента. Разбор на живом проекте

**Формат публикации:** Кейс (либо «Аналитика»).
**Сложность:** средняя. **Язык:** русский.

**Хабы** (4–5, больше не даёт смысла):

- Delphi
- Oracle
- C++
- Искусственный интеллект
- Open source

**Теги:** `delphi`, `oracle`, `c++`, `pl/sql`, `ии-агенты`, `легаси`, `интеграция`,
`sqlite`, `swift`, `автоматизация тестирования`

**Кат.** В тексте стоит `<cut/>` после вступления — Habr сам обрежет анонс по нему.
Если редактор ругается, замените на `<habracut/>`.

**Картинки.** В тексте они ссылками на `raw.githubusercontent.com`, поэтому статья
отображается сразу после вставки. Habr рекомендует свой хостинг: по желанию
перетащите те же файлы в редактор, он загрузит их в habrastorage и подменит ссылки.
Используются пять снимков:

| Файл в репозитории | Где в статье |
|---|---|
| `docs/screenshots/03_card_ru.png` | карточка компании, после таблицы компонентов |
| `crm_delphi/shots_gui/47_kanban_orders.png` | раздел про Delphi |
| `crm_delphi/shots_gui/11_duplicate.png` | самотест, отбитый дубликат |
| `crm_delphi/shots_gui/55_process_scheme.png` | постановка и порт |
| `docs/screenshots/08_sources_ru.png` | баг с выключенным источником |

**Перед публикацией стоит проверить:**

1. Заголовок вынесен в поле, из тела убран.
2. Кат на месте — анонс заканчивается на фразе про «одно условие».
3. Таблицы не разъехались (Habr иногда ломает широкие — самая широкая здесь на
   девять колонок, со счётчиками демо-данных).
4. Подсветка кода включилась: блоки помечены `bash`, `cpp`, `sql`.
5. Ссылки на репозиторий открываются.

**Чего в тексте намеренно нет:** упоминаний конкретных внутренних адресов, схем и
учётных данных заказчика. Имена таблиц ERP (`TMS_UNIVERS`, `A$ADM`) остались —
они уже опубликованы в самом репозитории и без доступа к серверу ничего не дают.

## Свой блог

`docs/article-ai-delphi-oracle-cpp.html` — страница целиком: шрифты с Google Fonts,
остальное внутри файла, картинок нет, светлая и тёмная темы переключаются
автоматически.

Три способа применить:

- **Как есть.** Залить файл на сайт — он открывается сам по себе, без сборки.
- **В свой шаблон.** Файл во фрагментной форме (`<title>`, `<style>`, затем
  `<div class="wrap">`) — содержимое `div` переносится в шаблон, стили берутся из
  блока `<style>`; переменные темы объявлены в `:root` и переопределяются для тёмной.
- **С картинками.** Если на площадке внешние картинки разрешены, вставьте те же
  снимки, что перечислены выше для Habr, — ссылки на `raw.githubusercontent.com`
  рабочие.

Статья также опубликована как приватная страница и доступна по ссылке, которую
можно открыть и переслать, не выкладывая никуда файл.
