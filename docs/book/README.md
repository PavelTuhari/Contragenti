# Книга о комплексе

`index.html` — одна страница: части по порядку, оглавление сбоку, схема
комплекса, галереи снимков и целиком те же документы, что лежат в
репозитории. Открывается двойным нажатием, ничего ставить не нужно.

Собрать заново:

```bash
python tools/make_book.py --all      # снимки + прогоны + сборка
python tools/make_book.py --build    # только пересобрать из md
```

| Что | Где |
|---|---|
| книга | `docs/book/index.html` |
| иллюстрации | `docs/book/img/` (кадры самотестов и снимки программ) |
| вывод проверок | `docs/book/logs/` (снят прогоном, не переписан) |
| состав книги | `tools/book/plan.py` |

Снимки для части про кассу делаются с работающих служб: перед `--shots`
поднимите имитатор (`python -m pos_bridge.fc_emulator serve`) и прослойку
(`python -m pos_bridge serve`).
