Зачем две программы

CRM не ходит на портал и не решает капчу. Утилита забирает карточку с date.gov.md и отдаёт XML. Демо-CRM только вызывает утилиту и пишет клиента в свою базу.

company_search.py

Contragenti

Поиск на date.gov.md через настоящий Chrome, локальная SQLite companies.db, карточка с учредителями и долгами, HTTP-API и режим --pick.

crm_delphi/ContragentiCRM.exe

Demo CRM

Окно в стиле EspoCRM, своя база clients.db. Кнопка «из реестра» запускает Contragenti и сохраняет выбранную карточку с дедупликацией по IDNO.

Капча. Не включайте «Скрытый браузер». В headless-режиме Google почти всегда требует ручную проверку, и поиск завершается по таймауту.

Шесть шагов установки

Команды — для PowerShell. Каталог клона может быть любым.

1

Клонировать репозиторий

& "C:\Program Files\Git\cmd\git.exe" clone https://github.com/PavelTuhari/Contragenti.git
cd Contragenti
2

Виртуальное окружение

py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
3

Самопроверка

.\.venv\Scripts\python.exe company_search.py --selftest
.\crm_delphi\ContragentiCRM.exe --selftest
4

Связать CRM с утилитой

Файл crm_delphi\crm.ini:

[contragenti]
launcher=C:\Contragenti\company_search.py
lang=ru
5

Запустить оба окна

start-contragenti.bat
start-demo-crm.bat

API: http://127.0.0.1:9393/health

6

Первый контрагент с портала

В Demo CRM: Клиенты → добавить из реестра. Выберите компанию в Contragenti. XML-карточка вернётся в CRM.

Какие атрибуты приходят в карточке

<counterparty source="date.gov.md" idno="1003600116460">
  <idno>1003600116460</idno>
  <denumire>...</denumire>
  <adresa>...</adresa>
  <administratori>...</administratori>
  <founders><founder name="..." share="..."/></founders>
  <debts currency="MDL"><debt nr="1" type="..." sum="..."/></debts>
</counterparty>
Полный текст: INSTALL_WINDOWS_ru.md. Данные: портал открытых данных Правительства Республики Молдова (date.gov.md).
