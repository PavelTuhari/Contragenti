Contragenti + Demo CRM для macOS

Пакет ставит в /Applications/Contragenti: утилиту Contragenti (поиск по реестру date.gov.md, локальный API 127.0.0.1:9393), Demo CRM (нативное приложение, интеграция через SDK), Contragenti Setup (мастер настройки и обновления), стартовые базы, SDK и инструкции. Интернет во время установки не нужен.

После установки откроется мастер настройки: он проверит Google Chrome, python3 (нужен только для SDK на Python), настроит Demo CRM и выполнит самопроверку. Данные программ хранятся в ~/Library/Application Support/Contragenti.

Программы не подписаны сертификатом Apple Developer ID — карантин снимается при установке; если Gatekeeper всё же не пускает: правый клик по приложению → «Открыть».
